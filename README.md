# KlipHub Site

Site institucional independente extraído da página institucional ativa do sistema KlipHub. O projeto contém somente o site e seus recursos visuais; não inclui o painel, backend ou dados do sistema.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Publicação

```bash
npm run build
```

O build estático fica em `dist/` e pode ser publicado em GitHub Pages, Vercel, Netlify ou outro host estático. Os botões de acesso direcionam para `https://kliphub.com.br/`.
